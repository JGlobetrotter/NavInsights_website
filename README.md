# Navisignal Insights Website

Navisignal Insights LLC — consulting website built in HTML, hosted via GitHub Pages at [navisignalinsights.com](https://navisignalinsights.com).

All Rights Reserved. Licensing requires permission.

## Contains
- Homepage with interactive buyer-type filter
- Services, About, Portfolio, Contact pages
- Free Templates & Tools with lead magnets (Kit/ConvertKit)
- Useful Links resource library
- Newsletter signup (Kit/ConvertKit)

## Structure
```
/
├── index.html, about.html, services.html ...  Pages
├── css/styles.css      All site styles
├── js/main.js          Navigation & interactions
├── assets/             Images and video
├── CNAME               Custom domain config
├── robots.txt          Search engine instructions
├── sitemap.xml         Page index for Google
└── docs/               Setup and reference guides
```
